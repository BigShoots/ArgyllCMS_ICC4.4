# ICC v4.4 PQ profile mode

This branch adds an opt-in ICC v4.4 display-profile mode to `colprof`.
The default output remains ICC v2.2.

Build ArgyllCMS in the usual way:

```sh
jam -q -fJambase -j 3
```

Create an RGB display profile carrying Rec. 2020 PQ full-range coding
metadata:

```sh
profile/colprof -4 -a X -q m display
```

The `-4` option is deliberately narrow. It is accepted only for RGB display
profiles and writes:

* ICC header version 4.4
* `desc` and `cprt` as `multiLocalizedUnicodeType`
* `cicp` as 9, 16, 0, 1 (Rec. 2020, ST 2084, RGB, full range)

The measured AToB and BToA transforms are generated by the same Argyll code
as the v2.2 profile. This keeps the profile fit unchanged while changing the
container and coding metadata.

Run the smoke test after building:

```sh
python3 contrib/test_icc44.py --colprof profile/colprof
```

For stricter interoperability testing, validate the generated profile with
the ICC reference `iccDumpProfile` tool:

```sh
iccDumpProfile -v --read 100 profile.icc ALL
```

Argyll private measurement tags may be reported as unknown by the reference
validator. Those warnings are independent of the v4.4 header, MLUC and CICP
encoding.

iccMAX is not ICC v4.4. The staged iccMAX boundary is documented separately
in `iccmax/README.md` and must produce an ICC v5 extended-range profile through
an ICC v5-aware serializer.
